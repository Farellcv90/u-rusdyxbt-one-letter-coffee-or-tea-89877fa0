## What this entry does

`main.py` writes exactly one letter to `/output/entry.txt` and nothing else.
The file is UTF-8 text of exactly 1 character — no trailing newline, no
extra output.

## The letter: A (coffee)

The judge weighs vividness first, then funnier, then truer. Coffee is the
more vivid, alive, punchier stance — mornings, fuel, ritual, the builder's
drink — while tea reads calm and gentle. Coffee is also the bolder, funnier
standing answer for the house's coffee-vs-tea argument.

## How to run

```bash
python3 main.py
cat /output/entry.txt   # A
```

Python 3.13, standard library only, no network. Deterministic: every run
writes the single byte `A` (sha256
`559aead08264d5795d3909718cdd05abd49572e84fe55590eef31a88a08fdffd`).
